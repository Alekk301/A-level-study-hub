# 90-second demonstration script

Target length: about 90 seconds at a calm speaking pace. Record the screen sections separately, then
edit them together. Keep the cursor slow and show only actions mentioned in the narration.

## Shot plan

| Time | Picture |
| --- | --- |
| 0–8 s | On camera; name and project |
| 8–20 s | Home page and four subjects |
| 20–38 s | Open Computer Science notes and use search |
| 38–57 s | Select text, save a highlight, refresh and show it restored |
| 57–72 s | Filter papers and open a QP/MS pair |
| 72–84 s | Brief GitHub architecture/test view |
| 84–90 s | On camera or return to home page |

## Voice-over

Hi, I’m Đức Anh Lê, or Alex Le, and this is my CAIE A-Level Study Hub.

I started it because revision materials for my classmates and me were spread across different sites
and folders. I wanted one free place that connected syllabus topics, useful notes, and past-paper
practice.

The hub covers four subjects and 153 syllabus topics. Students can search the notes, follow their
progress, save topics, and continue from where they stopped.

This highlighting feature came directly from a classmate, who asked if selected text could still be
there on the next visit. A highlight is stored in versioned browser state, and the app reconstructs
it when the topic is opened again.

The paper browser organises 919 question-paper and mark-scheme pairs. The files are not copied into
my repository; an allowlisted worker validates approved external PDF requests before previewing
them.

Behind the interface, routes call React views, views load structured JSON notes, and generated
indexes power search. Automated checks validate the content, saved state, routes and paper proxy.

I used ChatGPT, Codex and Claude extensively—about 60 to 70 percent of the code and content was
AI-assisted. My responsibility is the problem, product decisions, testing, verification, user
feedback, and learning to explain and maintain every part I publish.

## Recording note

Do not memorise the script word for word. Practise until the ideas are yours, then speak naturally.
If a sentence describes code you cannot yet explain, complete the relevant stage in
[LEARNING-GUIDE.md](LEARNING-GUIDE.md) before recording it.
