# Privacy

Last updated: 7 September 2026

CAIE A-Level Study Hub is a free study tool without user accounts. This note describes the current
application; it is not a general legal guarantee for future versions.

## Data kept in your browser

The site stores the following in `localStorage`:

- bookmarks and completed topics;
- syllabus checklist selections;
- saved text highlights;
- recent and last-opened topics;
- colour-theme preference; and
- analytics consent choice.

Study state is not sent to a project database. It stays in the current browser profile and can be
removed by clearing this site's data. Clearing it permanently removes local progress.

## Optional Google Analytics

Google Analytics is used to understand aggregate use, such as visits and useful routes. Its script
is not inserted until a visitor explicitly selects **Accept analytics**. Selecting **Decline**
prevents the script from loading for that browser unless site data is later cleared.

After acceptance, Google may process standard analytics information such as page path, approximate
location, device/browser details and request identifiers under Google's own terms. The integration
requests IP anonymisation, but no analytics service should be treated as risk-free.

Read [Google's privacy policy](https://policies.google.com/privacy) and
[analytics data safeguards](https://support.google.com/analytics/answer/6004245).

## External paper previews

The paper catalogue contains external URLs. Preview requests pass through an allowlisted Worker
endpoint and then to the approved PDF host. That host may receive normal web request data, including
IP address and browser headers. The project does not control the external host's retention policy.

## Contact

For ordinary privacy questions, open a GitHub issue without including personal information. For a
sensitive security or privacy problem, use
[GitHub's private vulnerability report](https://github.com/Alekk301/A-level-study-hub/security/advisories/new).

The project does not sell student data and currently has no advertising or user-profile system.
